# Planogram Studio

Веб-приложение для планограмм табачных шкафов, связанное с распознаванием полок SalesBox (IR).
В нём собирают шкаф в миллиметрах, раскладывают пачки, согласуют планограмму и публикуют её на
точки. Дальше каждое фото агента с этих точек проверяется по планограмме автоматически, а
результат виден в мониторинге.

## Как это работает

```
Шкаф → Планограмма → Согласование → Публикация на точки → Фото агента → Сверка в IR → Мониторинг
```

1. **Шкаф.** Размеры, полки, ряды толкателя. Шкафы хранятся в библиотеке с кодом вида `С1-96-170`.
2. **Планограмма.** Пачки из каталога раскладываются по полкам вручную или авто-раскладкой:
   обязательные SKU, доли производителей по контракту, уровень глаз, продажи. Проверки сразу
   показывают, что не помещается и чего не хватает.
3. **Согласование.** Черновик → на согласовании → утверждена → опубликована, с комментарием и
   автором на каждом шаге. Правка утверждённой планограммы начинает новую версию.
4. **Публикация.** Версия уходит в IR неизменной и назначается кластерам и отдельным точкам одной
   транзакцией. Перед публикацией видно, какие точки перейдут с другой планограммы.
5. **Сверка.** Агент присылает фото полки в IR с `outlet_id`. IR находит пачки, распознаёт SKU и
   сравнивает ряды с планограммой точки. Итог — процент соответствия (доля мест, где стоит нужная
   пачка) и наличие обязательных SKU.
6. **Мониторинг.** Соответствие по дням, точкам, кластерам и версиям, точки с худшей выкладкой
   сверху. Отдельное фото можно разобрать вручную в «Сверке IR» и подтвердить слоты.

## Из чего состоит

| Часть | Где | Что делает |
|---|---|---|
| Studio | этот репозиторий, `studio/` | интерфейс: React 19, TypeScript, Vite, Canvas 2D |
| Сервер Studio | репозиторий IR `salesbox-ir`, ветка `islambek/planogram-studio`, `service/.../api/studio.py` | пользователи и клиенты, хранение, публикация, назначения, мониторинг |
| Сверка с планограммой | репозиторий IR, `packages/shelf` (`align.py`) | выравнивание рядов фото с полками планограммы |

Данные клиентов разделены: пользователь видит шкафы, планограммы, точки и фото только своего
клиента. Вход по логину и паролю, сессия хранится в HttpOnly-куке. Роли: редактор, руководитель
(утверждает и публикует) и инженер IR (видит технические детали распознавания).

Без входа Studio работает в браузере: данные лежат в IndexedDB, обмен через «Выгрузить всё» и «Импорт».

## Запуск

```bash
cd studio
npm install
npm run dev          # http://localhost:5173, запросы /v1 уходят на IR-сервис 127.0.0.1:8000
npm run build        # статическая сборка в studio/dist
```

Сервер — IR-сервис из ветки `islambek/planogram-studio`:

```bash
uv run salesbox-api
uv run salesbox-studio-user add ira --name "Ирина" --role manager --client pmi
```

В проде Studio открывается с того же адреса, что и API: либо через `SALESBOX_API_STUDIO_DIR`
(сервис отдаёт `dist/` на `/studio/`), либо через CDN, который отдаёт статику и пересылает `/v1` на
сервис.
