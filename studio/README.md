# Planogram Studio · табак

Веб-приложение для планограмм табачных шкафов, связанное с Salesbox Shelf IR. В нём собирают шкаф в миллиметрах, ставят пачки по рядам толкателей и сохраняют готовую планограмму. Потом выбирают её в сверке: IR проверяет фото агента именно по этой планограмме, а человек подтверждает слоты, и из этого считается реальная точность.

План и решения Р1–Р7: https://claude.ai/artifact/EtsCxjoMZko3wXUrGwt6VD

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # статическая сборка в dist/
```

Для сверки нужен IR-сервис из `~/SalesBox(work)` с поддержкой поля `planogram`. Она лежит в ветке `islambek/planogram-studio`:

```bash
cd "~/SalesBox(work)" && git switch islambek/planogram-studio
uv run salesbox-api  # 127.0.0.1:8000; Studio ходит туда через прокси Vite (/v1)
```

Ключ API вводится в «Сверка IR → Подключение к IR-сервису». Другой адрес сервиса для прокси задаётся переменной `SALESBOX_API=http://host:port npm run dev`.

## Что внутри

| Раздел | Что делает |
|---|---|
| Шкафы | Библиотека шаблонов с кодом вида `С1-96-170` (номер, ширина и высота в см; можно задать свой). Конструктор: полки тянутся мышкой за номер слева или двигаются стрелками на 5 мм (⇧ — 25 мм). Синие ручки меняют ширину и высоту шкафа. Ещё в конструкторе: цоколь, лайтбокс, дверцы (стекло или шторка), материал, ширина рядов толкателя на шкаф или на полку, вместимость по форматам пачек, пачки для примера |
| Планограммы | Шкаф из библиотеки (своя копия) плюс раскладка. Есть перетаскивание из каталога и по холсту, фейсинги, режимы «Текстура», «Схема» и «IR-вид», правила (must-have, минимум фейсингов, доли по контракту, близнецы для IR), проверки, отмена (⌘Z), экспорт YAML для `align.py` и JSON |
| Каталог SKU | 265 меток галереи `recognition_ref` с числом эталонов. Формат пачки выводится из метки. Правятся производитель, сегмент, формат, размеры (замер), цена и EAN; можно добавить свои SKU |
| Сверка IR | Выбор готовой планограммы. «Фото → IR» отправляет фото вместе с YAML планограммы, в ответе статусы слотов на фото и на шкафу. Слоты подтверждаются клавишами (Enter — IR прав, X — ошибся). В памяти сверок видны точность и ошибка compliance. Кнопка «Новая версия по фото» делает версию планограммы из того, что увидел IR. Есть «Пример сверки без сервиса» и загрузка JSON результата |

Импорт принимает JSON v2 (родной формат), JSON v1 прототипа `planogram-studio-handoff` (см → мм) и YAML из `configs/planograms`.

Данные хранятся в `localStorage` этого браузера. Для обмена есть «Выгрузить всё» и «Импорт». Оригиналы фото не сохраняются, как и в IR-сервисе.

## Устройство

```
src/domain/     модель и логика без React: типы, форматы пачек, каталог из галереи, геометрия шкафа,
                проверки (пороги из configs/shelf/cigarettes.yaml), экспорт и импорт YAML для IR, JSON v2/v1,
                сопоставление PlanogramReport со слотами планограммы
src/render/     Canvas 2D: генератор текстур пачек (зона предупреждения по ТР ТС 035) и сцена шкафа
src/ui/         экраны: Planograms, Fixtures, Constructor, Editor, Catalog, Compare; общие компоненты
src/store.ts    zustand + localStorage, хеш-маршруты
src/data/gallery.json   снимок меток галереи и числа эталонов (outputs/recognition/gallery_shelf.npz)
```

Обновить снимок галереи:

```bash
cd "~/SalesBox(work)" && .venv/bin/python -c "import numpy as np,collections,json;d=np.load('outputs/recognition/gallery_shelf.npz');c=collections.Counter(map(str,d['labels']));print(json.dumps({'source':str(d['source']),'embedder':str(d['embedder']),'snapshot':'<дата>','labels':[{'label':k,'refs':v} for k,v in sorted(c.items())]},ensure_ascii=False))" > ~/planogram/studio/src/data/gallery.json
```

## Чего пока нет

- `align.py` не умеет сверять близнецов по бренду. Studio пишет их в YAML ключом `twins`, а сервис этот ключ игнорирует.
- Хранение на сервере (Postgres), версии с согласованием, назначение на точки, PDF и XLSX — Этап 3 плана.
- «Подогнать под шкаф» и «Разложить по правилам» — Этап 4.
- Текстуры из кропов галереи: в `.npz` только векторы, кропы нужно отдавать из Qdrant или из хранилища.
