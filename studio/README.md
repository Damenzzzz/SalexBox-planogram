# Studio · интерфейс

Описание проекта и пайплайна — в [README в корне](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173; другой адрес сервера: SALESBOX_API=http://host:port npm run dev
npm run build    # dist/
```

## Устройство

```
src/domain/   модель и логика без React: типы, каталог, геометрия шкафа, проверки, авто-раскладка,
              версии, выгрузки (YAML для IR, Excel, CSV замеров), сверка, клиент сервера и синхронизация
src/render/   Canvas 2D: пачки, шкаф, фото пачек с сервера
src/ui/       экраны: планограммы, шкафы, каталог, сверка, точки, мониторинг, помощь
src/store.ts  состояние (zustand), хранение в IndexedDB, вход и синхронизация с сервером
```

Синхронизация: документы целиком, изменения забираются по `seq`, запись идёт поверх `rev`. Если
документ одновременно правили в двух местах, действует серверная версия, а своя правка не
теряется: планограмма сохраняется копией, остальное можно вернуть из окна аккаунта.

## Внутри кабинета

Кабинет открывает Studio во фрейме с того же адреса: `index.html?host=salesbox`. Ключа и своего входа
в этом режиме нет, токен приходит сообщением и живёт только в памяти (`src/domain/host.ts`):

```
Studio → кабинет  { type: 'studio:ready' }
кабинет → Studio  { type: 'studio:session', token, organizationId, userName, apiBase }
Studio → кабинет  { type: 'studio:token-expired' }   сервер ответил 401: нужен новый токен
```

Сообщения принимаются только от родительского окна и только с того же адреса. Запросы идут на
`apiBase` с заголовком `Authorization: Bearer`; сверка фото идёт на `POST /v1/studio/check`, остальные
пути те же. Данные браузера лежат отдельно по организации. Сама по себе Studio работает как раньше.

```bash
npm test   # проверки режима кабинета, без браузера и сервера
```
